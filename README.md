*От диагноза — к решению. От ошейника — к рассвету.*

---

## 📖 О книге

**«Ошейник или рассвет»** — короткая публицистическая книга, которая за 9 разделов (пролог, 7 глав, эпилог) проводит читателя по трём смысловым блокам:

1. **Крах** — почему представительная демократия перестала работать как механизм: лоббизм, спектакль выборов, исчезающий между голосованиями избиратель.
2. **Ошейник** — как цифровая валюта центрального банка (CBDC) превращает удобство в инструмент контроля: программируемость денег, добровольность входа, электронный концлагерь без колючей проволоки.
3. **Свобода** — Экосистема ДАО как альтернатива: один человек — один токен, четыре гильдии, экономика 49/51, базовая потребительская корзина по праву рождения, ИИ-советник вместо диктатора.

Книга написана в жанре **философско-публицистического эссе** с опорой на цитаты из Библии (Мф. 9:17, Пс. 81:6) и содержит призыв к распространению идеи **народного самодержавия** и к участию специалистов в построении глобального проекта.

## 🚀 Как открыть

### Локально

1. Склонируйте репозиторий или скачайте ZIP:
   ```bash
   git clone https://github.com/abkostikov/collar-or-dawn.git
   cd collar-or-dawn
```

2. Откройте `index.html` в любом браузере.
3. **Важно:** не открывайте HTML прямо из архива — браузер не увидит ни картинок, ни языковых папок. Сначала распакуйте.

Работает полностью **офлайн**, интернет не требуется.

### Онлайн (GitHub Pages)

Самый быстрый способ получить публичную ссылку:

1. Зайдите в **Settings → Pages** этого репозитория.
2. В разделе **Source** выберите ветку `main` и папку `/ (root)`.
3. Нажмите **Save**. Через минуту сайт будет доступен по адресу:

```
https://abkostikov.github.io/collar-or-dawn/
```

Дополнительно можно подключить собственный домен — раздел **Custom domain** в тех же настройках.

## ✏️ Как дополнять

### Добавить новую языковую версию

1. Создайте папку с кодом языка (например, `it/` для итальянского).
2. Скопируйте `en/index.html` в неё.
3. Переведите текст, обновите `title`, `description`, `hreflang`, `og:locale` и `Schema.org`.
4. В **каждом** из существующих `index.html` добавьте `<link rel="alternate" hreflang="it" href="...">`.
5. В селекторе языков (`.lang-switch`) добавьте ссылку `IT`.

### Заменить картинки

Положите файлы в `/img/` с теми же именами (`01-prolog.jpg` … `09-epilog.jpg`). Если меняете расширение — обновите `src` во всех 8 версиях.

### Изменить домен для SEO

Перед публикацией замените `https://narodnoe-samoderjavie.org/` на ваш реальный домен в:

- `index.html` и 7 языковых версиях (в `canonical`, `hreflang`, `og:url`, `Schema.org`);
- `sitemap.xml`;
- `robots.txt`.
